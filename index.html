What I was actually trying to demonstrate

Both projects are built around the same idea: a result is worth what its verification is worth. Most of the engineering in each repository exists to make a claim checkable rather than to make it larger.

Measured, not remembered

Every number quoted anywhere — this site, the READMEs, the model card — is read from a metrics.json that regenerates from raw data on every push. Nothing is typed by hand, so nothing can quietly drift from the model it describes.

Reported against the hardest comparison

The forecasting project declares its baseline before fitting, then discovers the declared one is not the hardest — and quotes the smaller improvement against the hardest instead. The credit model's headline sits next to a logistic regression that beats it on the holdout.

Negative results kept

The retrieval layer was supposed to improve accuracy. It slightly degrades it, so the lesson says so and keeps the layer for a different, stated reason. A hypothesis about missing-data patterns was tested, rejected, and left in the docstring.

The bugs are in the history

A strategy reporting a Sharpe of 50 by trading a spread no instrument pays. A Docker path bug that reported model_loaded: false with no error. A segfault that 105 passing tests never saw. Each is a commit with the reasoning attached.

Statistics that can say "no"

The fairness test was replaced after the first version flagged all three protected attributes — because a bootstrap around a minimum-over-groups is biased, not because the model was unfair. The replacement finds one real disparity instead of three.

Built as a taught course

31 lessons that derive each decision before writing the code, with exercises and worked solutions. Several exercises are designed so the obvious approach fails instructively.

How to read this site. The interactive parts run on the real scored output of each pipeline — the held-out applicants with their actual probabilities and SHAP values, and the out-of-sample forecasts with their actual errors. The arithmetic in the browser is live; the model that produced the numbers ran offline. Where a chart could be mistaken for a live model, it says so.
