Organizational Thesis. Annual 360 performance reviews suffer from recency bias, political posturing, and lag reality by months. High-performing engineering teams need high-frequency, low-stakes micro-feedback that highlights collaboration patterns and surfaces interpersonal blockers before they turn into resignations or missed deadlines.

1. Behavioral Framework & ML Models

1. Micro-Descriptors

Replaces subjective grading with four concrete behavioral states: Collaborative (4.0), Neutral (3.0), Withdrawn (2.0), and Blocking (1.0).

2. Rolling Velocity & Trends

Engineers 7-day and 14-day exponential moving averages, score volatility, and mutual review reciprocity to filter individual bad days from genuine trend shifts.

3. Anomaly & Archetype Clustering

Unsupervised clustering segments team members into interaction archetypes (e.g. core amplifiers, quiet executors, friction points) to guide coaching interventions.

2. Streamlit Dashboard & LLM Synthesis

Interactive Team Dashboard

Team Overview: Real-time distribution of collaboration health scores, active team friction hotspots, and participation metrics.

Privacy Safeguards: Optional aggregate anonymization prevents retaliatory scoring and guarantees psychological safety.

Actionable 1-on-1 Insights

Grounded LLM Feedback: Synthesizes qualitative comments and numerical scores into structured talking points for engineering managers.

Reliable Fallback: Functions fully offline with deterministic heuristics when LLM API keys are not provided.

3. Running Locally

git clone https://github.com/nimb-ou/peer-review-system
cd peer-review-system
pip install -r requirements.txt
python src/data_generator.py   # Seed realistic 60-day team history
python src/ml_pipeline.py      # Train anomaly models
streamlit run streamlit_app/app.py
