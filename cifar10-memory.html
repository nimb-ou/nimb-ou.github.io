CIFAR-10 Vision Associative Memory

An exploration of non-backpropagation visual memory capacity. Projects 3,072-dimensional natural color image pixels into orthonormal associative memory prototype matrices, evaluating zero-gradient recall and quantization limits across 10 balanced visual categories.

Biological Plausibility. Cortical visual associative memory stores patterns via synchronous synaptic potentiation rather than end-to-end backpropagation through time. This project implements one-shot memory formation over complex, multi-channel color natural imagery.
