Dual-Index Hybrid Retrieval Engine

A multi-tiered vector search architecture. Routes incoming queries through an O(1) bit-exact byte hash cache (<5 μs) before falling back to a spatial KDTree index with inverse distance-weighted nearest-neighbor voting — providing high throughput and robust noise resistance.

Engineering Rationale. Traditional vector databases run heavy similarity calculations on every incoming query, even when many requests are identical or near-duplicates. This hybrid engine decouples exact lookups from approximate nearest neighbor retrieval, cutting 95th percentile latency drastically.
